# Assets & Legal Compliance Policy

**NFSMW: Rockport 2026** is a clean-room, open-source modding toolchain and remaster project for *Need for Speed: Most Wanted - Black Edition* (PS2, `SLUS-21351`).

## Zero Copyrighted Game Content Policy
This repository **does not** contain, host, or redistribute:
- PlayStation 2 disc images (`.iso`, `.bin`, `.chd`) or BIOS files
- Electronic Arts / Black Box executables (`SLUS_213.51`), archives (`ZDIR.BIN`, `ZZDATA*.BIN`, `.BUN`), models, audio, or original textures
- AI-upscaled derivatives of copyrighted game textures (which remain legally derivative works and are generated strictly locally on the user's machine from their own legally owned disc image)

## Permitted Assets in This Repository
Only the following asset categories may be committed to this repository or attached to releases:
1. **Original artwork, SVGs, shaders, and procedural scripts** created by project contributors (licensed under MIT or CC0-1.0).
2. **CC0 1.0 (Public Domain)** textures, HDRIs, and audio sourced from open libraries (e.g., Poly Haven, ambientCG, Kenney, OpenGameArt CC0, Freesound CC0).
3. **SIL OFL 1.1** open-source fonts (e.g., Rajdhani, Chakra Petch, Exo 2) bundled with their respective `OFL.txt` license files.
4. **MIT / ISC** icon packs (e.g., Tabler Icons, Lucide, Phosphor).
5. **Clean-room metadata, `.pnach` patches, binary-diff specifications, and C/MIPS source code** written for `ps2sdk`.
